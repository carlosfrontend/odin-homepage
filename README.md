# 🏠 Odin Homepage

Una landing page responsive desarrollada como parte del curso de **Advanced HTML and CSS** de [The Odin Project](https://www.theodinproject.com/). Este proyecto pone en práctica conceptos avanzados de diseño web, incluyendo maquetado semántico, Flexbox, CSS Grid y diseño adaptable a múltiples dispositivos.

🔗 **Vista en vivo:** [carlosfrontend.github.io/odin-homepage](https://carlosfrontend.github.io/odin-homepage/)

---

## 📚 Tecnologías utilizadas

- 🧱 **HTML5** – Estructura semántica y accesible.
- 🎨 **CSS3** – Estilos avanzados con uso de Flexbox y Grid.
- ⚙️ **JavaScript** – Interactividad básica.
- 📦 **Webpack** – Empaquetado y gestión de módulos.
- 🧪 **Jest** – Pruebas unitarias.
- 🧹 **ESLint** – Linter para mantener un código limpio y consistente.

---

## 🚀 Instalación y uso

1. 📥 **Cloná el repositorio:**

   ```bash
   git clone https://github.com/carlosfrontend/odin-homepage.git
   cd odin-homepage
   ```

2. 📦 **Instala las dependencias:**

   ```bash
   npm install
   ```

3. 💻 **Ejecuta el entorno de desarrollo:**

   ```bash
   npm run dev
   ```

4. 🏗️ **Construye el proyecto para producción:**

   ```bash
   npm run build
   ```
